DS 2.1 · decisions

What changed and why

Decisions from the DS 2.1 proposal, applied across the Project Overview screen below.

1

Product register, not brand register

Copy follows the product voice: utilitarian, terse, action-oriented. No marketing flourishes. Brand vs product for context.

2

Less card design on web

Sections separate via vertical spacing — no dividers, no framed wrappers. Cards are reserved for distinct entity tiles like tour rooms and water-mitigation areas.

3

Soft badge bgs & sizing

Status pills use soft tinted backgrounds (Done · In progress · Latest · SOW). Each is 20px tall with 4px padding on every side and a 16px icon separated from the label by 4px.

Done In progress Latest SOW
4

Beige palette for primary actions

Primary actions — desktop Open 360°, sidebar Open 360° tour, mobile Request sketch / Add SOW / Request estimate — use the three-state beige palette: Base new regular, Light hover, Dark new pressed. Text stays dark in every state.

5

Outline stroke — #e2e0d3

Outline buttons — desktop Edit · Share · More · row downloads; mobile View rooms · Share access — use a 1px light-grey stroke #e2e0d3 on a white background. No shadow.

Edit Share View rooms
6

8px gap between icon and text

On web buttons, the gap between leading icon and label is 8px. Equivalent to me-2 / ms-2 on a projected <svg-icon>.

▢ Open 360°
7

Main actions get icons

Primary CTAs — Open 360°, Edit, Share, Request estimate — carry a leading icon. Subtle utility actions like Generate and More stay text-only so secondary surfaces read calmer.

7b

Frequent utility actions stay quiet

Per-row download and edit actions render as icon-only 32×32 squares. The action is still recognisable, the row keeps more horizontal room for content, and the surface stays calm.

8

Grey secondary text

Density rail labels, section subtitles, sidebar IDs and copy badges use grey. Recipe: #1A1905 at opacity 0.65 with plus-darker blend — equivalent to #6a6a66 for secondary and #5a5a55 for muted.

secondary#6a6a66
muted#5a5a55
9

14px minimum body text

No 12px or 13px body copy on web. Body-sm is 14px. Badges keep the 12px caption size as the only documented exception.

9b

Lemon-lime #EAE658 — promos & decoration only

The pale lemon-lime tone replaces the old chartreuse #E5DF00 for very rare cases: marketing-style banners, promotional CTAs (e.g. the Initial Estimate banner's "Try it out"), and decorative emphasis. It is never used for primary actions or status. In legacy mode the token reverts to the old chartreuse.

bg-promo#eae658
Try it out
10

"NEW" tag is always green

Any NEW label flagging a freshly added item — sidebar Initial Estimate, future modules — uses the green badge style. Green is the most prominent tone in the palette and reads as "first time here". Other badge colours stay reserved for status (Done, In progress) or category (SOW, Latest).
