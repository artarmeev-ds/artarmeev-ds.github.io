DS 2.1 · decisions

What changed and why

Eight rules from the proposal. Status reflects what's currently rendered in the iframes below.

1 Applied

Product register, not brand register

Copy and tone follow the product voice: utilitarian, terse, action-oriented. No marketing flourishes. Reference: brand vs product.

2 Applied

Less card design on web

Sections separate via vertical spacing only — no dividers, no framed wrappers. Cards reserved for distinct entity tiles (tour rooms, water-mitigation areas).

3 Applied

Soft badge bgs & new sizing

Status pills use soft tinted backgrounds (Done · In progress · Latest · SOW). Per the new spec (Figma 17411-37773): 20px tall, 4px padding all sides, 16px icon with a 4px gap to text. Replaces the prior 16-tall wService badge with white text and a saturated bg.

4 Applied

Delete chartreuse — new beige palette for actions

The bright yellow #e5df00 is dropped. Primary actions (desktop "Open 360°", sidebar "Open 360° tour", mobile "Request sketch / Add SOW / Request estimate") now use the new beige three-state palette: Base new regular, Light hover, Dark new pressed. Text stays dark across all states.

5 Applied

Outline action stroke — #e2e0d3

Outline buttons (desktop Edit · Share · More · row downloads; mobile View rooms · Share access) keep the standard 1px light-grey stroke #e2e0d3 on a white background. No shadow. Per Figma node 17411-38483.

6 Applied

More space between icon and text on web

Button icon-text gap raised from 6px to 8px. Equivalent to me-2/ms-2 applied to projected <svg-icon>.

7 Applied

Main actions get icons; others stay text-only

Primary CTAs (Open 360°, Edit, Share, Request estimate) ship with leading icons. Subtle / utility actions (Generate, More) stay text-only to keep secondary surfaces calm.

8 Applied

Beige secondary text → grey

Density rail labels, section subtitles, sidebar IDs and copy badges drop the warm beige tones. Recipe: #1A1905 at opacity 0.65 + plus-darker blend, equivalent to grey #6a6a66 / #5a5a55.

9 Applied

14px minimum standalone plain text

No 12px or 13px body copy on web. Body-sm bumped from 13 to 14. Badges keep the 12px caption size as the only documented exception.
